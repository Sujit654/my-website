1. Sets

Basic Notation

A = {x : x satisfies a condition}
x ∈ A → x belongs to A
x ∉ A → x does not belong to A

Subset

A ⊆ B means every element of A belongs to B.
Number of subsets of a set containing n elements:

2ⁿ
Number of proper subsets:

2ⁿ - 1

Union and Intersection

A ∪ B = elements in A or B or both
A ∩ B = elements common to A and B
A - B = elements in A but not in B

Complement

A' = U - A

De Morgan's Laws

(A ∪ B)' = A' ∩ B'

(A ∩ B)' = A' ∪ B'

Number of Elements

n(A ∪ B) = n(A) + n(B) - n(A ∩ B)
n(A') = n(U) - n(A)
If A and B are disjoint:
n(A ∪ B) = n(A) + n(B)

2. Relations & Functions

Cartesian Product

A × B = {(a,b) : a ∈ A, b ∈ B}
If n(A)=m and n(B)=n:

n(A × B) = mn

Relation

A relation R from A to B is a subset of A × B.

Function

Every element of the domain has exactly one image.
f : A → B

Composition

(f ∘ g)(x) = f(g(x))
(g ∘ f)(x) = g(f(x))

Standard Functions

Identity function:
f(x)=x
Constant function:
f(x)=c
Modulus function:
f(x)=|x|
Signum function:
sgn(x)=1 if x>0
sgn(x)=0 if x=0
sgn(x)=-1 if x<0

3. Trigonometric Functions

Basic Ratios

sin θ = P/H
cos θ = B/H
tan θ = P/B
cosec θ = H/P
sec θ = H/B
cot θ = B/P

Reciprocal Relations

sin θ = 1/cosec θ
cos θ = 1/sec θ
tan θ = 1/cot θ

Fundamental Identities

sin²θ + cos²θ = 1

1 + tan²θ = sec²θ

1 + cot²θ = cosec²θ

Related Identities

tan θ = sin θ/cos θ
cot θ = cos θ/sin θ

Negative Angles

sin(-θ) = -sinθ
cos(-θ) = cosθ
tan(-θ) = -tanθ

Compound Angles

sin(A+B)=sinA cosB + cosA sinB

sin(A-B)=sinA cosB - cosA sinB
cos(A+B)=cosA cosB - sinA sinB

cos(A-B)=cosA cosB + sinA sinB
tan(A+B) = (tanA+tanB)/(1-tanA tanB)
tan(A-B) = (tanA-tanB)/(1+tanA tanB)

Double Angle

sin2A = 2sinA cosA
cos2A = cos²A - sin²A
= 2cos²A - 1
= 1 - 2sin²A
tan2A = 2tanA/(1-tan²A)

Half Angle

sin²(A/2) = (1-cosA)/2
cos²(A/2) = (1+cosA)/2

Sum to Product

sinA + sinB = 2sin((A+B)/2)cos((A-B)/2)
sinA - sinB = 2cos((A+B)/2)sin((A-B)/2)
cosA + cosB = 2cos((A+B)/2)cos((A-B)/2)
cosA - cosB = -2sin((A+B)/2)sin((A-B)/2)

Degree and Radian

180° = π radians

1° = π/180 radians

1 radian = 180°/π

Standard Values

θ 0° 30° 45° 60° 90°
sinθ 0 1/2 1/√2 √3/2 1
cosθ 1 √3/2 1/√2 1/2 0
tanθ 0 1/√3 1 √3 undefined
cosecθ undefined 2 √2 2/√3 1
secθ 1 2/√3 √2 2 undefined
cotθ undefined √3 1 1/√3 0

4. Complex Numbers & Quadratic Equations

Imaginary Unit

i = √(-1)

i² = -1
i³ = -i
i⁴ = 1
iⁿ repeats every 4 powers.

Complex Number

z = a + ib
Real part = Re(z)=a
Imaginary part = Im(z)=b

Conjugate

If z=a+ib:

z̄ = a-ib
z z̄ = a²+b²

Modulus

|z| = √(a²+b²)

Argument

tan θ = b/a

Quadratic Equation

ax²+bx+c=0
x = (-b ± √(b²-4ac))/(2a)
D=b²-4ac

5. Linear Inequalities

Basic Rules

If a>b:
a+c>b+c
If a>b and c>0:
ac>bc
If a>b and c<0:
ac
The inequality sign reverses when multiplying/dividing by a negative number.

Interval Notation

x>a → (a,∞)
x≥a → [a,∞)
x x≤a → (-∞,a]

6. Permutations & Combinations

Factorial

n! = n(n-1)(n-2)...3×2×1
0! = 1

Permutation

ⁿPᵣ = n!/(n-r)!

Combination

ⁿCᵣ = n!/[r!(n-r)!]

Relations

ⁿPᵣ = r! × ⁿCᵣ
ⁿCᵣ = ⁿCₙ₋ᵣ
ⁿC₀ = ⁿCₙ = 1
ⁿC₁ = ⁿCₙ₋₁ = n

Important Identity

ⁿCᵣ + ⁿCᵣ₋₁ = ⁿ⁺¹Cᵣ

7. Binomial Theorem

Expansion

(a+b)ⁿ = Σ ⁿCᵣ aⁿ⁻ʳ bʳ

r=0 to n

General Term

Tᵣ₊₁ = ⁿCᵣ aⁿ⁻ʳ bʳ

First Terms

(a+b)² = a²+2ab+b²
(a+b)³ = a³+3a²b+3ab²+b³
(a-b)² = a²-2ab+b²
(a-b)³ = a³-3a²b+3ab²-b³

Middle Term

If n is even:
one middle term = T₍ₙ/₂₊₁₎
If n is odd:
two middle terms = T₍ₙ₊₁₎/₂ and T₍ₙ₊₃₎/₂

8. Sequence & Series

Arithmetic Progression

a, a+d, a+2d, ...
aₙ = a+(n-1)d
Sₙ = n/2[2a+(n-1)d]
Sₙ = n/2(a+l)

Geometric Progression

a, ar, ar², ar³, ...
aₙ = arⁿ⁻¹
Sₙ = a(rⁿ-1)/(r-1)
r ≠ 1
Equivalent:
Sₙ = a(1-rⁿ)/(1-r)

Infinite GP

S∞ = a/(1-r)
|r|<1

Standard Sums

1+2+3+...+n = n(n+1)/2
1²+2²+...+n² = n(n+1)(2n+1)/6
1³+2³+...+n³ = [n(n+1)/2]²

9. Straight Lines

Distance

Distance between (x₁,y₁) and (x₂,y₂):

√[(x₂-x₁)²+(y₂-y₁)²]

Slope

m=(y₂-y₁)/(x₂-x₁)

Slope Angle

m=tanθ

Equation of Line

y=mx+c
y-y₁=m(x-x₁)
y-y₁ = [(y₂-y₁)/(x₂-x₁)](x-x₁)

Two Point Form

(y-y₁)/(y₂-y₁) = (x-x₁)/(x₂-x₁)

Intercept Form

x/a + y/b = 1

General Form

Ax+By+C=0

Parallel Lines

m₁=m₂

Perpendicular Lines

m₁m₂=-1

Angle Between Lines

tanθ = |(m₂-m₁)/(1+m₁m₂)|

Distance from Point to Line

Distance = |Ax₁+By₁+C|/√(A²+B²)

10. Conic Sections

Circle

x²+y²=r²
(x-h)²+(y-k)²=r²
Centre = (h,k)
Radius = r

Parabola

y²=4ax
x²=4ay
For y²=4ax:
Vertex=(0,0)
Focus=(a,0)
Directrix: x=-a
For x²=4ay:
Focus=(0,a)
Directrix: y=-a

Ellipse

x²/a² + y²/b² = 1
a>b
c²=a²-b²
Eccentricity:
e=c/a

Hyperbola

x²/a² - y²/b² = 1
c²=a²+b²
e=c/a

11. Introduction to 3D Geometry

Coordinates

A point in 3D is represented by:

(x,y,z)

Distance Formula

Distance between (x₁,y₁,z₁) and (x₂,y₂,z₂):

√[(x₂-x₁)²+(y₂-y₁)²+(z₂-z₁)²]

Origin

Origin = (0,0,0)

Distance from Origin

√(x²+y²+z²)

12. Limits & Derivatives

Basic Limit Laws

lim [f(x)+g(x)] = lim f(x)+lim g(x)
lim [f(x)g(x)] = (lim f(x))(lim g(x))

Important Trigonometric Limits

lim(x→0) sinx/x = 1
lim(x→0) tanx/x = 1
lim(x→0) (1-cosx)/x² = 1/2

Derivative Definition

f'(x) = lim(h→0) [f(x+h)-f(x)]/h

Basic Derivatives

d/dx(c)=0
d/dx(xⁿ)=nxⁿ⁻¹
d/dx(sin x)=cos x
d/dx(cos x)=-sin x
d/dx(tan x)=sec²x
d/dx(cot x)=-cosec²x
d/dx(sec x)=secx tanx
d/dx(cosec x)=-cosecx cotx

Sum Rule

d/dx[f(x)+g(x)] = f'(x)+g'(x)

Product Rule

d/dx(uv)=u(dv/dx)+v(du/dx)

Quotient Rule

d/dx(u/v) = [v(du/dx)-u(dv/dx)]/v²

13. Statistics

Mean

Mean = Σx/n
For frequency distribution:

Mean = Σfᵢxᵢ / Σfᵢ

Mean Deviation

MD about mean = Σ|xᵢ-x̄|/n
For frequency distribution:

MD = Σfᵢ|xᵢ-x̄|/Σfᵢ

Variance

σ² = Σ(xᵢ-x̄)²/n
For frequency distribution:

σ² = Σfᵢ(xᵢ-x̄)²/Σfᵢ

Standard Deviation

σ = √σ²

Coefficient of Variation

CV = (σ/x̄) × 100

14. Probability

Probability

P(E)= Number of favourable outcomes / Total number of equally likely outcomes

Range

0 ≤ P(E) ≤ 1

Impossible Event

P(∅)=0

Sure Event

P(S)=1

Complement

P(E')=1-P(E)
P(E)+P(E')=1

Addition Rule

P(A∪B) = P(A)+P(B)-P(A∩B)
If A and B are mutually exclusive:

P(A∪B)=P(A)+P(B)

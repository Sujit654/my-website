1. Real Numbers

Euclid's Division Lemma

a = bq + r
where 0 ≤ r < b

HCF and LCM

For two positive integers a and b:

HCF(a,b) × LCM(a,b) = a × b

Prime Factorisation

If
a = p₁ᵃ × p₂ᵇ × p₃ᶜ ...

then prime factorisation can be used to find HCF and LCM.
HCF: Take the smallest powers of common prime factors.

LCM: Take the greatest powers of all prime factors.

Important Result

If p is a prime number and p divides a², then p divides a.

2. Polynomials

Quadratic Polynomial

For polynomial:

ax² + bx + c

where a ≠ 0

Zeroes

If α and β are zeroes of ax² + bx + c:

α + β = -b/a

αβ = c/a

Polynomial from Zeroes

If α and β are zeroes:

x² - (α + β)x + αβ
General quadratic polynomial:

a[x² - (α + β)x + αβ]

Division Algorithm

Dividend = Divisor × Quotient + Remainder

3. Pair of Linear Equations in Two Variables

General Form

a₁x + b₁y + c₁ = 0

a₂x + b₂y + c₂ = 0

Number of Solutions

Unique solution:
a₁/a₂ ≠ b₁/b₂
No solution:
a₁/a₂ = b₁/b₂ ≠ c₁/c₂
Infinitely many solutions:
a₁/a₂ = b₁/b₂ = c₁/c₂

Cross Multiplication

x/(b₁c₂ - b₂c₁) = y/(c₁a₂ - c₂a₁) = 1/(a₁b₂ - a₂b₁)

Substitution

Find one variable in terms of another and substitute into the second equation.

Elimination

Multiply equations so that the coefficient of one variable becomes equal and eliminate it.

4. Quadratic Equations

Standard Form

ax² + bx + c = 0
a ≠ 0

Quadratic Formula

x = (-b ± √(b² - 4ac)) / 2a

Discriminant

D = b² - 4ac
D > 0 → Two distinct real roots

D = 0 → Two equal real roots

D < 0 → No real roots

Sum and Product of Roots

α + β = -b/a

αβ = c/a

5. Arithmetic Progressions

Basic Form

a, a+d, a+2d, a+3d, ...
a = first term
d = common difference

Common Difference

d = second term - first term

nth Term

aₙ = a + (n - 1)d

Sum of n Terms

Sₙ = n/2 [2a + (n - 1)d]
Also:

Sₙ = n/2 (a + l)

where l = last term

Last Term

l = a + (n - 1)d

6. Triangles

Similar Triangles

Corresponding sides of similar triangles are proportional.

Basic Proportionality Theorem

If a line is drawn parallel to one side of a triangle, it divides the other two sides proportionally.

Pythagoras Theorem

Hypotenuse² = Perpendicular² + Base²

c² = a² + b²

Area of Similar Triangles

Area₁ / Area₂ = (Corresponding side₁ / Corresponding side₂)²

Similarity Criteria

AAA
SSS
SAS

7. Coordinate Geometry

Distance Formula

Distance = √[(x₂-x₁)² + (y₂-y₁)²]

Section Formula

If P divides A(x₁,y₁) and B(x₂,y₂) in ratio m:n:

P = ((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n))

Midpoint Formula

((x₁+x₂)/2 , (y₁+y₂)/2)

Area of Triangle

Area = 1/2 |x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|

Collinear Points

If area of triangle formed by three points = 0, then the points are collinear.

8. Introduction to Trigonometry

Trigonometric Ratios

sin θ = Perpendicular / Hypotenuse

cos θ = Base / Hypotenuse

tan θ = Perpendicular / Base

cosec θ = Hypotenuse / Perpendicular

sec θ = Hypotenuse / Base

cot θ = Base / Perpendicular

Reciprocal Relations

sin θ = 1/cosec θ
cos θ = 1/sec θ
tan θ = 1/cot θ
cosec θ = 1/sin θ
sec θ = 1/cos θ
cot θ = 1/tan θ

Important Identities

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ

Other Relations

tan θ = sin θ / cos θ

cot θ = cos θ / sin θ

Standard Values

θ 0° 30° 45° 60° 90°
sin θ 0 1/2 1/√2 √3/2 1
cos θ 1 √3/2 1/√2 1/2 0
tan θ 0 1/√3 1 √3 Not defined
cosec θ Not defined 2 √2 2/√3 1
sec θ 1 2/√3 √2 2 Not defined
cot θ Not defined √3 1 1/√3 0

9. Some Applications of Trigonometry

Basic Relations

tan θ = Height / Distance
Height = Distance × tan θ
Distance = Height / tan θ
sin θ = Height / Hypotenuse
cos θ = Distance / Hypotenuse

Important Terms

Angle of Elevation: Object is above the observer's horizontal line.
Angle of Depression: Object is below the observer's horizontal line.

10. Circles

Tangent

The tangent at any point of a circle is perpendicular to the radius through the point of contact.

Tangents from External Point

The lengths of tangents drawn from an external point to a circle are equal.
If PA and PB are tangents:

PA = PB

Radius and Tangent

Radius ⟂ Tangent at point of contact.

11. Areas Related to Circles

Circle

Circumference = 2πr
Area = πr²
Diameter = 2r
r = d/2

Semicircle

Area = 1/2 πr²
Curved Surface Length = πr

Sector

Area of sector = θ/360 × πr²
Length of arc = θ/360 × 2πr

Segment

Area of segment = Area of sector - Area of triangle

π

π = 22/7
or approximately 3.14159

12. Surface Areas and Volumes

Cuboid

Volume = lbh
TSA = 2(lb + bh + hl)
LSA = 2h(l+b)

Cube

Volume = a³
TSA = 6a²
LSA = 4a²

Cylinder

Volume = πr²h
CSA = 2πrh
TSA = 2πr(h+r)

Cone

Volume = 1/3 πr²h
Slant height:
l = √(r²+h²)
CSA = πrl
TSA = πr(l+r)

Sphere

Volume = 4/3 πr³
Surface Area = 4πr²

Hemisphere

Volume = 2/3 πr³
CSA = 2πr²
TSA = 3πr²

Combination of Solids

Total Volume = Sum/Difference of individual volumes
Total Surface Area = Only exposed surfaces are added.

13. Statistics

Mean

For ungrouped data:

Mean = Σx / n
For frequency distribution:

Mean = Σfx / Σf

Assumed Mean Method

Mean = a + (Σfd / Σf)

Step Deviation Method

Mean = a + h(Σfu / Σf)

Median

Median = l + [(n/2 - cf)/f] × h

Mode

Mode = l + [(f₁-f₀)/(2f₁-f₀-f₂)] × h

Empirical Relation

Mode = 3 Median - 2 Mean
Here:
l = lower boundary of median/modal class
h = class size
f = frequency of median class
cf = cumulative frequency before median class

14. Probability

Probability Formula

P(E) = Number of favourable outcomes / Total number of equally likely outcomes

Range of Probability

0 ≤ P(E) ≤ 1

Impossible Event

P(impossible event) = 0

Sure Event

P(sure event) = 1

Complementary Event

P(not E) = 1 - P(E)
P(E) + P(not E) = 1
